### Messages

- It is a **fundamental unit of context for models in LangChain**.
- Messages are used to **communicate with the model** and provide context for generating responses.
- It is an object that contains:
    1. **Role**: The role of the message sender (e.g., system, user).
    2. **Content**: The actual text or information being sent in the message (like text, images, audio, etc.).
    3. **Metadata**: Optional additional information about the message (e.g., timestamp, message ID, token usage).

- LangChain provides a standard message type.
- It works across all model providers, ensuring consistent behavior regardless of the model being used.
- Whenever model gives a response, it is `AIMessage` and when user sends a message, it is `HumanMessage`.
    ```python
    groq_model.invoke("Hello, how are you?") # AIMessage(type='ai')
    ```

###### Message Types
- All the below message types are available in `langchain.messages` module.
    1. `SystemMessage`: Tells the model how to behave or what to do.
    2. `HumanMessage`: Represents a message sent by a human user.
    3. `AIMessage`: Represents a message sent by the AI model in response to a user message.
    4. `ToolMessage`: Represents the output of tool calls.


#### Text Prompts

- Text prompts are strings that are sent to the model to generate a response.
- We no need to retain conversation history when using text prompts.
    ```python
    groq_model.invoke("Hello, how are you?")
    ```
- It is helpful when:
    - We want to **send a single message** to the model without any context.
    - We want to **generate a quick response** without maintaining conversation history.
    - We don't need to **retain conversation history** for future interactions.


#### Message Prompts

- You can pass a list of messages to the model to provide context for generating a response.
    ```python
    messages = [
        HumanMessage(content="What is the capital of France?"),
        AIMessage(content="The capital of France is Paris.")
    ]
    groq_model.invoke(messages)
    ```
