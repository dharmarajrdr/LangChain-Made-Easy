### Structured Output

- Models can be requested to return structured output in a specific format. 
- This is useful when you want the model to return data in a predictable way, such as JSON or a specific schema.
- Without structured output, the model's responses can be unpredictable and may require additional parsing or processing.
- Structured output can be achieved by providing the model with a schema using `pydantic` or other similar models. 
- This allows the model to understand the expected format and return data accordingly.
- Different models support structured output in different ways.
    1. **Pydantic:**  `pydantic`'s `BaseModel` + `model.with_structured_output(<Schema>)`
    2. **TypeDict:** `TypeDict` + `response_format=<Schema>` in `createAgent()`
    3. **Dataclass:** `@dataclass` + `response_format=<Schema>` in `createAgent()`

- [This](../code/src/code/05%20-%20Structured%20Output.ipynb) notebook demonstrates:
    - How to get structured output from a model.
    - How to define a schema using `pydantic`'s `BaseModel`.
    - How to work with nested structured output.

- `TypeDict` and `Dataclass` are also supported for defining schemas, but `pydantic` provides the richest feature set with `Field` validation, descriptions, and nested structures.

- How TypeDict differs from Pydantic is: 
    - instead of extending `BaseModel`, we have to extend `TypedDict` to define the schema.
    - instead of `Field`, we have to use `typing.Annotated` to add descriptions to the fields.

- With `TypeDict`, instead of extending `BaseModel`, we define the schema by extending `TypedDict` and using `typing.Annotated` for field descriptions.
- With `Dataclass`, instead of extending `BaseModel`, we define the schema by `@dataclass` decorator.
- Both TypeDict and Dataclass is supported in the `createAgent()` method by setting `response_format=<Schema>`.
    ```python
    agent = createAgent(
        model=groq_model,
        response_format=Movie   # <-- Movie Schema extends pydantic's BaseModel
    )
    ```

- Only difference between Pydantic, TypeDict and Dataclass is how we define the schema. The rest of the functionality remains the same.
