### Tools

- We already saw in [Create Agent.ipynb](../code/src/code/01%20-%20Create%20Agent.ipynb) about how to use tools with an agent using `langchain`'s **create_agent** function.
- That is one way to use tools with an agent, but there is another way to use tools with a model directly.

- Models can request external tools to fetch real-time information and provide the output to the user.
- Tools can perform various tasks like fetching data from APIs, databases, or even other LLMs.

    ```python
    from langchain.tools import tool

    @tool
    def get_current_weather(location: str) -> str:
        """
        Get the current weather for a given location.
        """
        return f"The current weather in {location} is 25°C and sunny."
    ```

- When any function is decorated with `@tool`, it becomes a tool that can be used by the model to fetch real-time information.
- Take a look at the code [here](../code/src/code/04%20-%20Tools.ipynb) to see how to use tools with a model directly.
