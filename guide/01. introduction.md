- First what is `LangChain`?
- Think of `LangChain` as a framework that provides tools and abstractions to make it easier to work with large language models (LLMs) and integrate them into your applications.
- Say, you want to build an application that uses a LLM to answer questions based on a specific dataset. 
- **Instead of writing all the code from scratch to handle the LLM, you can use `LangChain` to simplify the process.**

### Setting up the project

- It is always a good practice to create a virtual environment for our project.
- We can use `uv` to create a virtual environment.
    ```bash
    # Install uv if you don't have it already
    brew install uv
    ```
- Then go to your project directory and run the following commands:
    ```bash
    # Initialize the project
    uv init

    # Create a virtual environment
    uv venv

    # Activate the virtual environment (macOS)
    source .venv/bin/activate

    # Install latest version of listed dependencies
    uv add -r requirements.txt

    # To install specific dependency
    uv add ipykernel

    # To deactivate the virtual environment
    deactivate
    ```
- Here, [.venv](../code/.venv) is similar to `node_modules` in Node.js and `target` in Java. It contains all the dependencies for our project.
