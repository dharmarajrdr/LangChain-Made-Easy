- First what is `LangChain`?
- Think of `LangChain` as a framework that provides tools and abstractions to make it easier to work with large language models (LLMs) and integrate them into your applications.
- Say, you want to build an application that uses a LLM to answer questions based on a specific dataset.

### Setting up the project

- It is always a good practice to create a virtual environment for our project.
- We can use `uv` to create a virtual environment.
    ```bash
    # Install uv if you don't have it already
    brew install uv
    ```
- Then go to your project directory and run the following commands:
    ```bash
    # Initialize the project
    uv init

    # Create a virtual environment
    uv venv

    # Activate the virtual environment (macOS)
    source .venv/bin/activate

    # Install latest version of listed dependencies
    uv add -r requirements.txt

    # To install specific dependency
    uv add ipykernel

    # To deactivate the virtual environment
    deactivate
    ```
- Here, [.venv](../code/.venv) is similar to `node_modules` in Node.js and `target` in Java. It contains all the dependencies for our project.

### Agents

- A simple `Generative AI` application looks like this:
    ```mermaid
    graph LR
        A["Draft an email to HR \n (Input)"] --> B[LLM]
        B --> C["Dear HR, I'm Dharmaraj... \n (Output)"]
    ```
- LLM have cutoff knowledge and do not have up-to-date information.

- Imagine the following scenario:

    ```mermaid
    graph LR
        A["How much RCB scored in today's match? \n (Input)"] --> B[LLM]
        B --> C["I do not have any information about the match. \n (Output)"]

        classDef output fill:#f1100077,stroke:#333,stroke-width:2px;
        class C output;
    ```

- To overcome this limitation, LLM should depend on external tools to fetch real-time information. These tools can be APIs, databases, or even other LLMs.

    ```mermaid
    graph LR
        A["How much RCB scored in today's match? \n (Input)"] -- 1 --> B[LLM]
        B -- 6 --> C["The score is 263/5. \n (Output)"]
        B -- 2 --> D[External Tool]
        D -- 3 --> E["Fetching real-time data from API \n (Tool)"]
        E -- 4 --> D
        D -- 5 --> B

        classDef output fill:#11f00077,stroke:#333,stroke-width:2px;
        class C output;
    ```

- So, this is nothing but a simple `Agent` that can **use external tools to fetch real-time information and provide the output to the user**.

- An `Agent` is able to take simple decisions like where to fetch the information from, how to solve the problem, and how to provide the output to the user.

- Before langchain, `ReAct` architecture was used to build agents. But now, `LangChain` provides a simple and easy way to build agents.

- Take a look [here](../code/src/code/Create%20Agent.ipynb), to know how can we create an agent using `LangChain`.
- From the above code, we had a hands-on experience of creating an agent with a single tool. 
- We can add multiple tools to the agent and it will decide which tool to use based on the prompt.
